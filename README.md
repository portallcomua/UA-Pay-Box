# Universal Pay Box PRO 1.2.0

Автономна монетизація для WordPress (без WooCommerce і платіжних API).

## Як це працює
1. Приват24 → створіть Конверт.
2. **UA Pay Box → Послуги**: проект = назва плагіна + посилання на Конверт + вартість (+ термін, тексти листів).
   Плагіни Voice ADD створюють свій проект самі при активації — вам лишається вказати Конверт і вартість.
3. Користувач натискає «Купити PRO» → попап (копіювання логіна) → Конверт відкривається в новій вкладці, PRO вмикається одразу.
4. **UA Pay Box → Контроль Преміумів**: перевіряєте Приват24; немає оплати — «❌ Відключити PRO / Заблокувати».
   Користувачу автоматично йде лист (текст — у проекті) з посиланням на Конверт. Надійшла оплата — «✅ Розблокувати (повернути PRO)».

## Підключення будь-якого плагіна
У проекті (Послуги → Редагувати) є готовий блок «Код інтеграції» (PHP / HTML / REST).
Основне: `wcc_check_user_premium($user_id, $service_id)`, `upb_service_id('slug')`, `upb_buy_button($id, 'Купити PRO')`.
Хуки: `upb_premium_activated`, `upb_premium_blocked`, `upb_premium_unblocked`, `upb_premium_expired`.

Старий плагін «Universal Monetization & Billing» (universal-monetization.php) треба ДЕАКТИВУВАТИ — він використовує ті самі імена функцій.

## Плагіни на чужих сайтах (режим «Домен»)
Voice ADD ставляться на сайти клієнтів, де логін майже завжди «admin», тому PRO там прив'язано до ДОМЕНУ.
У проекті оберіть «Що клієнт вказує в коментарі: Домен». Плагін клієнта звертається до цього сайту через REST
(`/wp-json/upb/v1/service|status|activate`). У «Контроль Преміумів» з'являється колонка «Домен»; блокування за доменом
надсилає лист на email, указаний клієнтом при активації. Адресу сервера клієнт може змінити в налаштуваннях плагіна
(за замовчуванням https://uaserver.pp.ua).
